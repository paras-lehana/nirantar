Where it ran · how to reuse · guardrails on the agent that built it

Surfaces

  • Snowsight CoCo panel: 20+ chats, parallel sessions, workspace files, skills in .snowflake/cortex/skills/
  • CoCo Automations: Morning Reliability Briefing ($nirantar-reliability-brief)
  • Cortex Agent in the Streamlit app and in Snowflake CoWork for business users

Reuse in another account

  • Snowsight: upload skills/ to .snowflake/cortex/skills/
  • CLI: cortex skill add https://github.com/paras-lehana/nirantar
  • Plugin manifest .cortex-plugin/plugin.json; start with /nirantar-synthetic-plant

Guardrails for CoCo itself

  • Least privilege: built as role NIRANTAR_BUILDER
  • Cost caps: resource monitor, CoCo credit caps, X-Small warehouse
  • Workspace rules (AGENTS.md): no auto-approval, sensor-fault veto, journal row per milestone
